## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/satyammishra55555/portfolio.git
```

Go to project

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Run application

```bash
ng serve
```

Open

```
http://localhost:4200
```
